Privacy Policy

Belfius Personal is a private, personal-use application used to retrieve account information and transaction data from a Belfius account through an authorised Open Banking provider.

Data processing

The application processes account and transaction information solely for the personal financial management purposes of its owner.

Data sharing

Personal financial data is not sold, rented or shared with third parties for advertising or marketing purposes.

Data storage

Authentication credentials, API credentials and private cryptographic keys are stored locally and are not published in the application's source code repository.

Contact

For questions regarding this application, contact the application owner at the email address associated with the application.
